# SECURE ONBOARDING CLI
Secure C++ CLI for industrial onboarding - input validation, billing & grading logic with do-while loops.

Built as part of BCS @ Zetech University.

## Features
- Electrical Bill System - 20 households cost split
- Grading Logic - 0-100 validation with do...while
- Discount System
- Library Fine System

## Secure Coding Techniques
- do...while validation loops
- Input sanitization for negative numbers
- Loop guards

## How to Run
g++ file.cpp -o app
./app
